# requirements.md

## 機能要件

### 組織情報入力

| # | 要件 |
|---|------|
| F-01 | 組織名を入力できる（`user_group.user_group_name` / `member.company_name` に反映） |
| F-02 | 都道府県コードを入力できる（デフォルト: `13`） |
| F-03 | 市区町村コードを入力できる（デフォルト: `13101`） |
| F-04 | 利用開始日を入力できる（任意、`member_role_periods.period_from` に反映） |
| F-05 | 利用終了日を入力できる（任意、`member_role_periods.period_to` に反映） |

### アカウント入力

| # | 要件 |
|---|------|
| F-06 | 教師・生徒それぞれのアカウント一覧を表形式で入力できる |
| F-07 | 各行にユーザーID・ユーザー名・パスワードを入力できる |
| F-08 | 行を追加できる（教師: `t-N`、生徒: `s-N` のプレフィックス付き ID を自動採番） |
| F-09 | 行を削除できる |
| F-10 | 一覧を初期状態にリセットできる |
| F-11 | Excel / Google スプレッドシートからコピーしたタブ区切りデータをペーストで複数行展開できる |
| F-12 | ユーザーIDが空の行は SQL 生成時に除外される |

### SQL 生成

| # | 要件 |
|---|------|
| F-13 | 「SQL生成」ボタンで `users` 系・`member` 系 SQL を同時に生成できる |
| F-14 | パスワードは SQL 生成時に bcrypt（salt rounds: 10）でハッシュ化される |
| F-15 | パスワード未入力時はデフォルト値 `password` をハッシュ化する |
| F-16 | 生成 SQL は `START TRANSACTION` / `COMMIT` でラップされる（ただしユーザー・メンバーが 0 件の場合はコメントのみ出力） |
| F-17 | 教師は `role_id = 1`、生徒は `role_id = 2` で挿入される |
| F-18 | メールアドレスは `{ユーザーID}@{mailDomain}` で自動生成される |

### SQL 出力

| # | 要件 |
|---|------|
| F-19 | 生成した SQL をクリップボードにコピーできる |
| F-20 | コピー後に「コピーしました」フィードバックが表示される |
| F-21 | 生成した SQL を `.sql` ファイルとしてダウンロードできる |
| F-22 | ダウンロードファイル名は `{組織名}_users.sql` / `{組織名}_members.sql`（組織名未入力時は `sql_export_users.sql` / `sql_export_members.sql`） |
| F-23 | SQL が空の場合、コピー・ダウンロードボタンは無効になる |

## 非機能要件

| # | 要件 |
|---|------|
| NF-01 | クライアントサイドのみで動作する（バックエンドサーバー不要） |
| NF-02 | 静的サイトとして GitHub Pages 等にデプロイできる |
| NF-03 | 日本語入力（IME）が正常に動作する |
| NF-04 | パスワードは平文で SQL に出力されない |
| NF-05 | 大量アカウント入力時にパフォーマンスが著しく低下しない（制限目安: 数百件） |
