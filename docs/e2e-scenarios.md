# e2e-scenarios.md — E2E テストシナリオ

Playwright MCP が E2E テストを実施するためのシナリオ集。

本アプリケーションは認証不要のシングルページツールのため、テストユーザーは不要。

---

## 結果の報告形式

各シナリオの結果を以下のステータスで報告する。

| ステータス | 意味 |
|----------|------|
| OK | 期待値通り |
| NG | 期待値と異なる（再現手順と実際の挙動を記載） |
| SKIP | 技術的制約等で実行不可（理由を記載） |

---

## 初期表示

| # | 手順 | 確認観点 | 期待値 |
|---|------|---------|-------|
| 1 | アプリの URL にアクセスする | ページタイトル表示 | 「アカウントSQL生成ツール」と表示される |
| 2 | 組織情報フォームを確認する | 初期値 | 都道府県コード `13`・市区町村コード `13101` が入力されている。組織名・開始日・終了日は空 |
| 3 | スプレッドシートエリアを確認する | テーブル表示 | 教師・生徒それぞれの入力テーブルが表示される |
| 4 | SQL 出力エリアを確認する | 初期状態 | 2つの出力エリア（users SQL・member SQL）が空で表示される |
| 5 | コピー・ダウンロードボタンを確認する | 初期無効状態 | SQL 未生成の状態でコピー・ダウンロードボタンが無効（disabled）になっている |

## スプレッドシートへの貼り付け

| # | 手順 | 確認観点 | 期待値 |

| 1 | 教師テーブルの先頭セルをクリックし、タブ区切りの複数行データをペーストする（例: `teacher01\t山田太郎\tpassword1`） | 貼り付け動作 | 複数行にわたってデータが展開される |
| 2 | 生徒テーブルに複数行データをペーストする | 貼り付け動作 | 生徒テーブルに複数行にわたってデータが展開される |
| 3 | 組織名フォームにテキストをペーストする | フォームへのペースト | フォームに貼り付けられ、スプレッドシートに誤ってデータが入らない |

## SQL 生成

| # | 手順 | 確認観点 | 期待値 |
|---|------|---------|-------|
| 1 | 組織名を入力してデータを入力し「SQL生成」ボタンをクリックする | 生成処理・ローディング | 「生成中…しばらくお待ちください」のローディング表示が現れる |
| 2 | 生成完了後、users SQL 出力エリアを確認する | users SQL の内容 | `START TRANSACTION;` で始まり `COMMIT;` で終わる SQL が表示される |
| 3 | 生成完了後、member SQL 出力エリアを確認する | member SQL の内容 | `START TRANSACTION;` で始まり `COMMIT;` で終わる SQL が表示される |
| 4 | users SQL に入力した組織名・ID が含まれることを確認する | SQL の正確性 | 入力した組織名・ユーザー ID が SQL 内に反映されている |
| 5 | member SQL にメールアドレス（`{ユーザーID}@kankouyohou.com`）が含まれることを確認する | メールドメイン | `{ユーザーID}@kankouyohou.com` 形式のメールアドレスが含まれる |
| 6 | 開始日・終了日を入力して生成し、member SQL に期間が反映されることを確認する | 期間の反映 | `period_from`・`period_to` に指定した日付が含まれる |
| 7 | 開始日・終了日を空のまま生成し、member SQL を確認する | 期間未入力時 | `period_from`・`period_to` が `NULL` になる |
| 8 | パスワード未入力のデータで生成し、SQL を確認する | デフォルトパスワード | `password` をハッシュ化した値が使われる |

## クリップボードコピー

| # | 手順 | 確認観点 | 期待値 |
|---|------|---------|-------|
| 1 | SQL 生成後、users SQL エリアの「コピー」ボタンをクリックする | コピー成功フィードバック | 「コピーしました」が 2 秒間表示される |
| 2 | SQL 生成後、member SQL エリアの「コピー」ボタンをクリックする | コピー成功フィードバック | 「コピーしました」が 2 秒間表示される |
| 3 | 「コピーしました」表示が 2 秒後に消えることを確認する | フィードバックの自動非表示 | 2 秒後に表示が消える |

## ファイルダウンロード

| # | 手順 | 確認観点 | 期待値 |
|---|------|---------|-------|
| 1 | SQL 生成後、users SQL エリアの「ダウンロード」ボタンをクリックする | ダウンロード | `{組織名}_users.sql` というファイル名でダウンロードされる |
| 2 | SQL 生成後、member SQL エリアの「ダウンロード」ボタンをクリックする | ダウンロード | `{組織名}_members.sql` というファイル名でダウンロードされる |
| 3 | 組織名に記号・スペースを含む値（例: `テスト 学校！`）を入力して生成・ダウンロードする | ファイル名サニタイズ | 記号・スペースが除去されたファイル名（例: `テスト学校_users.sql`）でダウンロードされる |
| 4 | 組織名が空の状態で SQL 生成後にダウンロードする | フォールバックファイル名 | `sql_export_users.sql` / `sql_export_members.sql` でダウンロードされる |
