# product.md

## 目的

教育機関のデータベース管理者・システム担当者が、教師・生徒のアカウントを一括登録するための SQL INSERT 文を手軽に生成できるツール。
スプレッドシートからのコピー&ペーストで大量データを入力し、`users` 系・`member` 系テーブルへの SQL を即時に出力する。

## 対象ユーザー

| ユーザー | 説明 |
|----------|------|
| データベース管理者 | 教育機関のシステムに教師・生徒アカウントを一括登録する担当者 |
| システム担当者 | 年度始め等に大量アカウントを DB に投入する IT 担当者 |

## 成功指標

- Excel / Google スプレッドシートからのコピー&ペーストで入力が完結する
- SQL 生成ボタン1クリックで `users` 系・`member` 系 SQL が同時に出力される
- 生成された SQL をコピーまたは `.sql` ファイルとしてダウンロードできる
- パスワードが bcrypt ハッシュに自動変換され、平文が SQL に含まれない
